计算机采用补码表示数据，若用原码乘法计算两个数的乘积，还需要进行原码和补码间的转换，为减少处理环节，人们提出了补码乘法，又称为Booth算法。

以下内容以例题：

用补码一位乘法计算x * y

x = 0.10110 ， y = - 0.00011 为例。

<!-- more -->

#### 1.Booth算法

设 [ x ]<sub>补</sub> = x<sub>0</sub>.x<sub>1</sub>...x<sub>n</sub> ，[ y ]<sub>补</sub> = y<sub>0</sub>.y<sub>1</sub>...y<sub>n</sub> 

##### 1.被乘数x符号任意，乘数y符号为正：

 **[ x * y ]<sub>补</sub> =  [ x ]<sub>补</sub> * y**

##### 2.被乘数x符号任意，乘数y符号为负：

 **[ x * y ]<sub>补</sub> = P<sub>n + 1</sub> =P<sub>n</sub> + （y<sub>1</sub> - y<sub>0</sub>）[ x ]<sub>补</sub>**  

#### 2.补码一位乘法算法

1.乘数y采用单符号位，末位添加附加位y<sub>n + 1</sub>，初始值为0。

2.部分积根据y<sub>n </sub>y<sub>n + 1</sub>来进行判断：

​		y<sub>n </sub>y<sub>n + 1</sub> = 00或11时，P = P + 0；

​		y<sub>n </sub>y<sub>n + 1</sub> = 10时，P = P +  [ - x ]<sub>补</sub>；

​		y<sub>n </sub>y<sub>n + 1</sub> = 01时，P = P +  [ x ]<sub>补</sub>；

3.按上述算法进行n + 1次累加，n次右移操作即可完成乘积运算。

 例子：

[ x ]<sub>补</sub> = 0.10110， [ - x ]<sub>补</sub> = 1.01010 ，[ y ]<sub>补</sub> = 1.11101

| 部分积                                          | 乘数y (末尾添加附加位y<sub>n + 1</sub>初始为0) | 说明                                                         |
| ----------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| 00.00000<br>+     11.01010                      | 1111010                                        | P<sub>0</sub> = 0<br>y<sub>n </sub>y<sub>n + 1</sub> = 10 ，+ [ - x ]<sub>补</sub> |
| 11.01010<br>→    11.10101<br>+     00.10110     | 0111101                                        | 右移一位得 P<sub>1</sub> <br/>y<sub>n </sub>y<sub>n + 1</sub> = 01 ，+ [ x ]<sub>补</sub> |
| 00.01011<br>→    00.00101<br>+      11.01010    | 1011110                                        | 右移一位得 P<sub>2</sub> <br/>y<sub>n </sub>y<sub>n + 1</sub> = 10 ，+ [ - x ]<sub>补</sub> |
| 11.01111<br>→     11.10111<br>+       00.00000  | 1101111                                        | 右移一位得 P<sub>3</sub> <br/>y<sub>n </sub>y<sub>n + 1</sub> = 11 ，+0 |
| 11.10111<br>→      11.11011<br>+       00.00000 | 1110111                                        | 右移一位得 P<sub>4</sub> <br/>y<sub>n </sub>y<sub>n + 1</sub> = 11 ，+0 |
| 11.11011<br>→      11.11101<br>+       00,00000 | 1111011                                        | 右移一位得 P<sub>5</sub> <br/>y<sub>n </sub>y<sub>n + 1</sub> = 11 ，+0 |
| 11.11101                                        | 11110                                          | 最后一步不移位                                               |

所以 [ x * y ]<sub>补</sub> = 1.1110111110

x * y = - 0.0001000010
