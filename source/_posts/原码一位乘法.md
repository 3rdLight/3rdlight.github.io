以下内容以例题：

用原码一位乘法计算x * y

x = - 0.11111 ， y = 0.11101 为例。

<!-- more --> 

#### 1.运算方法

##### 1.乘积符号的确定

被乘数 [ x ]<sub>原</sub> = x<sub>0</sub>.x<sub>1</sub>...x<sub>n</sub> ，乘数[ y ]<sub>原</sub> = y<sub>0</sub>.y<sub>1</sub>...y<sub>n</sub>  ，x<sub>0</sub>和y<sub>0</sub>为乘数和被乘数的符号位，原码乘积的符号与两个符号位的关系为异或，即 **P<sub>f</sub> = x<sub>0</sub> ⊕ y<sub>0</sub>**  ("⊕"为异或符号，两数相同为0，不同为1) ，即被乘数与乘数同号，乘积为正，异号则为负。

例题 [ x ]<sub>原</sub> = 1.11111 ，[ y ]<sub>原</sub> = 0.11101 ，P<sub>f</sub> = x<sub>0</sub> ⊕ y<sub>0</sub> = 1 ⊕ 0 = 1 ，乘积为负。

##### 2.乘积的数值

乘积的运算为以下递归公式：

**P<sub>i + 1</sub> = ( P<sub>f</sub> + y<sub>n - i</sub> | x | )2<sup>-1</sup>** 

该公式采用递归计算乘积，设置累加寄存器存放部分积P，初始值P<sub>0</sub> = 0，每得到一个位积（公式中的P<sub>f</sub> + y<sub>n - i</sub> | x | ）就累加到寄存器中，然后逻辑右移一位（公式中的2<sup>-1</sup>）得到新的P值

例：

| 部分积                                           | 乘数 \| y \| (部分积右移掉的数为1<br>                 就在乘数前面补1，为0补0) | 说明                                                   |
| ------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------ |
| 00.00000<br>+      00.11111                      | 11101                                                        | y<sub>5</sub> = 1, + \|x\|<br>P<sub>0</sub> = 0        |
| 00.11111<br>→    00.01111<br>+      00.00000     | 11101<br>11110                                               | y<sub>4</sub> = 0, + 0，<br/>右移一位得P<sub>1</sub>   |
| 00.01111<br/>→    00.00111<br>+      00.11111    | 11110<br>11111                                               | y<sub>3</sub> = 1, + \|x\|<br/>右移一位得P<sub>2</sub> |
| 0**1**.00110<br/>→    00.10011<br>+     00.11111 | 11111<br>01111                                               | y<sub>2</sub> = 1, + \|x\|<br/>右移一位得P<sub>3</sub> |
| 0**1**.10010<br>→    00.11001<br>+     00.11111  | 01111<br>00111                                               | y<sub>1</sub> = 1, + \|x\|<br/>右移一位得P<sub>4</sub> |
| 0**1**.11000<br/>→    00.11100                   | 00111<br>00011                                               | 右移一位得P<sub>5 </sub>                               |

符号位 P<sub>f</sub> = x<sub>0</sub> ⊕ y<sub>0</sub> = 1

所以  [ x * y ]<sub>原</sub> = 1.1110000011

x * y =  - 0.1110000011

从上例可知：

两个n位数参加乘法运算要进行n次加法n次位移操作

加法运算可能会产生局部溢出，如上表中加粗的“ 1 ”，注意在进行逻辑右移操作时要将进位位移如部分积的最高位（不是补0）

例：

正常时00.01111进行逻辑右移后为00.00111，但0**1**.10010右移后为00.11001
